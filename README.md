# Jumper

![Jumper demo: Back, Forward, Toggle, and History](extension/media/demo.gif)

A browser-style Back button for your Mac's apps: a [Raycast](https://www.raycast.com) extension that steps back and forward through your recently used apps.

- **Using it:** see [`extension/README.md`](extension/README.md) (commands, hotkey setup, how it works). That README is the one shown on the Raycast Store.
- **The extension:** everything that ships to the Store lives in [`extension/`](extension/). Run npm commands there (`cd extension && npm ci && npm run dev`).
- **Developing:** dev docs live at the repo root: [`CLAUDE.md`](CLAUDE.md) (commands, layout, invariants), [`docs/`](docs/) (decisions, status, releasing, performance, research), and [`scripts/`](scripts/) (latency bench, Store media generator).
