How it works

Apps come from the order macOS already keeps for Cmd+Tab, so nothing runs in the background. Search and Agents read each app when you open them.

Search

  • Apps are ordered by recent use; within an app, active tabs come first.
  • Search forgives typos ("caude" finds Claude) and matches app names first: an app's own tabs before tabs that mention it.
  • Picking an entry selects it in its app and brings the app to the front.
  • Copy URL and Copy Title are in the action panel.
  • Recently Closed reopens browser tabs, Notion pages, Obsidian notes, and documents closed since Search last looked (a week, up to 100). Terminals, chats, and private windows stay out of it.
  • Apps Hopper can't read show under Unavailable, with a shortcut to the settings pane that fixes it.

Agents

  • Status comes from the agents themselves: Claude Code's list of running sessions, Codex's thread log, Cursor's flags, herdr's detection. No hooks to install, and nothing to undo when you switch tools.
  • Needs You is an agent stopped on a prompt: a permission request or a question. Done means it finished since you last looked, in the agent's own app or by jumping to it from Hopper.
  • Jumping goes to where it runs: the exact iTerm split or cmux terminal, the herdr pane, the Claude session, the Cursor agent.
  • Projects are git repositories; worktrees count as their main repository. Filter the list by project.

Apps

  • The first Back takes a snapshot of your app order and moves one step back. Further Backs go deeper; Forward retraces.
  • Switching any other way starts fresh. Click an app or press Cmd+Tab and the forward history is dropped, the way visiting a new page works in a browser.
  • You land where you left off. With Accessibility, an app comes back to the window you were in, like Cmd+Tab.
  • Remove from History (⌃X) hides an app until you use it again. Exclude (⌃⇧X) hides it for good.

Setup

  1. Install Hopper from the Raycast Store.
  2. Record hotkeys in Raycast Settings → Extensions → Hopper. Extensions can't set them.
  3. The first time you open Search, allow Automation (once per app) and Accessibility.
CommandHotkey
Toggle⌘⌘ double tap
Search⌃⌃ double tap
History⌃⌘ press and release
Back / Forward⌃⌘[ ⌃⌘]
Agents⌥⌘ press and release
Next Agent⌥⌘]

Each level has a base: the base alone opens its list, [ and ] step back and forward. These avoid the tab-switching keys of browsers, terminals, and editors. ⌥⌘] unfolds code in VS Code and Cursor, and ⌃⌃ is taken if macOS Dictation is set to “Press Control Key Twice”.

Back, Forward, Toggle, and History need no permissions. With Accessibility granted to Raycast, they switch like Cmd+Tab, so an app comes back to the window you left. Agents and Next Agent read the agents' own files and need no permission of their own. Jumping into a terminal pane uses the same Automation permission as Search.
