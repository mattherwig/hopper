Commands

Six commands. Bind the ones you use to hotkeys.

Suggested keys shown; assign your own in Raycast Settings → Extensions → Jumper.

⇧⌘[

Back

Switch to the app you used before this one. Run again to keep going back.

⇧⌘]

Forward

Retrace a Back step.

⌘⌘

Toggle

Flip between your two most recent apps. Run again to flip back.

History

History

Running apps from most to least recent. Jump to any, remove or exclude apps.

Tabs

Tabs

How it works

Browser rules, applied to apps

For apps, Jumper reads the order macOS already keeps for Cmd+Tab: nothing runs in the background, and it needs no permissions. Tabs asks once for Automation and Accessibility so it can read other apps' tabs and windows.

First Back takes a snapshotYour current app order is remembered and you move one step back. Further Backs go deeper; Forward retraces.
Switching manually starts freshClick an app or Cmd+Tab and the forward history is dropped, just like visiting a new page in a browser.
Quit apps are skippedClose something mid-walk and Jumper steps over it instead of reopening it.

Setup

Two minutes

  1. Install Raycast, then install Jumper from the Raycast Store.
  2. Open Raycast Settings → Extensions → Jumper.
  3. Assign hotkeys to Back, Forward, and Toggle. ⇧⌘[ / ⇧⌘] also switch tabs in many apps; a Raycast hotkey wins, so pick ⌃⌥[ / ⌃⌥] if you rely on those.
